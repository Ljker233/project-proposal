### Project title

Boardgame Companion

### What and why?

Board games are a common form of entertainment for us. However, we often encounter issues while playing them, including but not limited to not knowing the rules, lacking the necessary game tools, and having trouble remembering details. Therefore, a companion tool that assists players during gameplay can improve the gaming experience to some extent. For example, features such as score tracking, card tracking, dice rolling, rule lookup, quick-response questions, and random number generation would be very helpful.

### For whom?

This software is useful for single person or private groups of friends, classmates, or family members who would like to play boardgames.

### How?

The software intends to include the following functions:

1. Player Setup: The user can choose what function he wants to use before the game starts.

2. Score & Card Tracking: The user can use this software to track each player's score, or number of cards remain in the deck, hand, or elsewhere in real time.

3. Places to write down rules or take notes: The user can have spaces to write down part of the rules of the game in case the game is too complicated or confusing. To allow user to attach photo or PDF would also be ideal. The user can also have spaces to take there own notes during the game to prevent forgetting.

4. Utility Tools for boardgames: The software is also planned to provide useful tools such as roll dices, generate random numbers or groups of player, set the timer or countdown, set buttons for trivia questions and so on.

5. Game Lobbies or other customized functions for specific games: If there are games that need help other than the functions listed above, the software can provide extension to specific games if needed, such as common poker games or mah-jong.


### Scope

This project is appropriate for a team of 4 - 6 programmers because the process of development is highly flexible. Since each help module is relatively independent, we can flexibly add or remove features based on the timeline and the complexity of each module.
